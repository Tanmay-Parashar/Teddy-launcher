# Teddy's Launcher

Minimal, monochrome Android launcher.

- Home: big thin clock + date (long-press to switch black / white / red), 4-app dock
- Swipe up: dark text app drawer, search at the bottom (Enter launches first match)
- Long-press any app: pin to dock, app info, uninstall
- StandBy: charge the phone in landscape on the home screen for a big clock (red + dim at night)

Build: push to GitHub, open the Actions tab, run "Build APK", download the `monolith-apk` artifact.
